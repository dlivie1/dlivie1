## How I work with AI agents

- **Plan, then build:** every phase starts read-only, and nothing changes until I approve the plan.
- **Evidence over agreement:** the builder must confirm or push back on review findings with file and line references.
- **Memory in files:** a spec, a decision log and progress files, so any fresh session can pick up where the last one stopped.
- **Guardrails by default:** secret scanning at commit and push, no secrets in chat or on command lines, and one big change at a time.
